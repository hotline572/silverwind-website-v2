# TSR Wheels Website V2

A premium, black-and-gunmetal automotive website for TSR Wheels built with Next.js and Tailwind CSS.

## Pages

- Home
- Products
- Dealer Program
- About
- Contact

## Homepage Sections

- Hero with TSR headline and dual calls to action
- Featured Wheels
- Dealer Application
- Trust Indicators
- Gallery
- Conversion CTA

## Tech Stack

- Next.js App Router
- React
- TypeScript
- Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Production

```bash
npm run build
npm run start
```
